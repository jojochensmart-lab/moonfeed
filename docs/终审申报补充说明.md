## 可供终审使用的功能范围表述

MoonFeed 是 MoonBit 原生的 JSON Feed 1.1、RSS 2.0 和 Atom 1.0 解析与规范化库。统一入口输出 Feed/FeedItem；Atom 文档入口另行区分 Feed 与独立 Entry，并保留标准元数据、XML Base、语言和扩展树。输入由调用方提供，项目不负责 HTTP 下载、HTML autodiscovery、内容渲染或 Atom Publishing Protocol。

当前源码完整验证了已声明的常用字段、作者/语言继承、链接/附件、日期与 typed errors，具有六个可运行示例和 Node.js CLI。具体支持字段与信息损失边界见 [README](../README.md)；实现和测试证据见 [申报书功能实现对照表](申报书功能实现对照表.md)。

完整 RFC 4287 兼容仍是后续目标。本轮不把三个 PARTIAL 改写为 PASS，也不据此声称权威认证、用户规模、性能数据、生产部署或保证获奖。若终审硬性要求无条件完整 RFC 4287，则当前三个规范边界仍需解决；现有材料没有提供足以排除该要求的组委会细则。
