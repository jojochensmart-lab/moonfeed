## 本轮修改记录

1. JSON attachment：有序、多字段、非负有限时长、UInt64 字节数及错误路径；保留旧扩展忽略策略。
2. RSS：限定无 namespace 的核心子节点，处理 `xmlns=""` 与 itunes 声明作用域；拒绝根节点外字符与 CDATA；channel language 传入 item。
3. 日期与集合：阻止 Int 溢出；Atom Feed/条目继承作者数组独立。
4. CLI/API：修复版本、item language；根包重导出统一模型与 FeedFormat；保留 XML 原因。
5. 工程交付：新增四个示例、源码/registry 验收脚本、精确打包排除中文申报书。
6. 规范审计：补 email 合法 DEL 字符；将尚不完整的 obsolete quoted-pair 覆盖从旧 PASS 纠正为 PARTIAL。

原有测试的更动不是删减：JSON “附件忽略”用例升级为具体附件字段断言；CLI 版本断言改为 0.2.0；7 个 Podcast 样例去掉误写进 XML 字符串末尾的逗号，字段断言保留。新增非法文档外字符用例确保不再靠忽略尾随数据通过测试。
